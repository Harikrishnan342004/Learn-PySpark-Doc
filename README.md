# PySpark Data Processing – Hands-on Practice

This repository contains my hands-on practice and exercises while learning the core concepts of **PySpark**. The goal of this project is to understand how large-scale data processing works using Apache Spark and to perform common data operations similar to SQL and Python Pandas.

## 📌 Project Overview

In this repository, I practiced the essential PySpark operations required for data processing and data engineering tasks. Each concept is implemented with practical examples using datasets.

The topics covered include:

* Loading and exploring datasets
* Handling missing data
* Cleaning and transforming data
* Aggregating data
* Filtering datasets
* Pivoting data
* Writing processed data back to storage

These exercises help demonstrate how Spark can efficiently process large datasets in a distributed environment.
